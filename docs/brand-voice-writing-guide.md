# Brand voice — writing guide (derondsgnr)

**Purpose:** Canonical editorial rules derived from the Brivvy **derondsgnr brand voice** profile. Use this for longform, UI copy, threads, case studies, and anything that should sound like you—not generic “AI thought leadership.”

**How to use:** Keep this file as the reference. For AI-assisted drafting, paste the **Compact instructions** block at the end (or point agents at this path).

**Source:** Settings captured from Brivvy (`app.brivvy.io`) — **Tone** sliders + **Rules** tab — as configured when this doc was written (2026-05-08).

## Tone (sliders, 1–10)

Interpret these as tendencies, not stereotypes. When in doubt, favor clarity over performance.

| Dimension | Value | Plain meaning |
|-----------|-------|----------------|
| Warmth | 6 | Human and approachable, not syrupy. |
| Confidence | 8 | Say what you know; state tradeoffs plainly. |
| Formality | 6 | Professional, still conversational. |
| Playfulness | 8 | Room for voice and wit; avoid gimmicks that dilute the point. |
| Technical depth | 7 | Go deep when it helps; skip theater. |

## Linguistic behavior

| Setting | Choice |
|---------|--------|
| Default pronoun perspective | First-person |
| Sentence voice | Active |
| Slang level | Frequent |
| Emoji frequency | Minimal |
| Gender-neutral inclusive wording | On |
| Language sensitivity level | Moderate |

**Operating notes**

- Default to **I / we** where honest (“I ship…”, “We wire…”), not distant third person.
- Prefer **active voice**; if a sentence hides the actor, rewrite it.
- **Slang allowed**—natural, not forced. Avoid empty hype phrases even if the “slang” dial is up.
- **Emojis:** rare; never as a substitute for a precise line.
- **Inclusive wording:** use gender-neutral phrasing; “they/them” for unknown subjects is fine.

## Compact instructions (paste for AI tools)

Use American English. First-person where honest; active voice. Frequent natural slang; emojis minimal; inclusive wording on. Moderate sensitivity—direct, not cruel.

Tone: warm-6, confident-8, formal-6, playful-8, technical-7. No corporate filler.

Punctuation: no Oxford comma; en dashes for ranges and compounds; spaced en dash for multi-word compounds; ellipsis is three spaced periods; avoid semicolons and exclamation marks; no plus-sign “+” between words—use “and”; contractions minimal; `&` allowed.

Structure: concise paragraphs; short lists inline; long lists bullet with periods; links as Markdown.

Numbers: comma thousands; spell out under ten; ordinals as words; big abbreviations (M/K only) in headings if needed; imperial measurements, abbreviated units.

Dates/times: `DD Month, YYYY` or abbreviated month when tight; 12-hour with **a.m./p.m.**; timezone when needed.

Headings: title case (Chicago); concise; no emojis in headings.

Do not sound like LinkedIn thought leadership. Prefer concrete mechanisms, tradeoffs, and what is actually live vs cut vs unfinished.
